# WANTED 6 — 15分逃げ切れ

GTAシリーズ風の「手配度」システムを再現した、2Dトップダウン（上下左右移動）のブラウザゲームです。
`index.html` を開くだけで遊べます（ビルド・依存なし）。

## ルール
- **15分間生き延びればクリア**。HPが0、または逮捕ゲージが満タンになるとBUSTED。
- 手配度は時間経過で ★1 → ★6 へ順に上昇します（敵の数・出現ペースも増加）。
- 敵を倒すとレベルアップで最大HPが増え、HP回復・アーマーのアイテムをドロップします。
- **アイテムを一定数（3個〜）取得するたびに、3択で強化を選びます**：攻撃力UP / 連射力UP / 移動速度UP / 味方の追加。

## 手配度と出現勢力（GTA: San Andreas 準拠）
| 手配度 | 開始時間 | 勢力・イベント |
|---|---|---|
| ★1 | 0:00 | 警官（警棒で殴る・逮捕を試みる / 拳銃 Colt45）、白バイ |
| ★2 | 2:00 | 警官・白バイの全員が銃を使用 |
| ★3 | 5:00 | ショットガン警官、**道路封鎖（ロードブロック）** |
| ★4 | 8:00 | SWAT、警察ヘリコプター（建物越しに飛行・攻撃） |
| ★5 | 11:00 | FBI |
| ★6 | 13:30 | 軍隊（兵士・装甲車・ライノ戦車） |

## 味方（複数人・複数パターン）
| 種類 | 特徴 |
|---|---|
| 護衛兵 | ピストルで連射、常に援護 |
| スナイパー | 超長射程・高威力・低連射 |
| ショットガン兵 | 近距離高火力・HP高め |
| 衛生兵 | 定期的にプレイヤーを回復 |

味方はプレイヤーの周囲を護衛して自動で射撃します（最大12人）。敵弾や爆発で倒されることもあります。

**味方は手配度が上がるほど自動で強化されます**（耐久力・攻撃力・連射速度）。★が上がった瞬間にHPも少し回復します。

| 手配度 | HP倍率 | 火力倍率 | 連射倍率 |
|---|---|---|---|
| ★1 | ×1.0 | ×1.0 | ×1.0 |
| ★3 | ×2.4 | ×1.8 | ×1.24 |
| ★6 | ×4.5 | ×3.0 | ×1.6 |

衛生兵の回復量も手配度で増え、近くの味方も回復します。

## 操作
| 入力 | 動作 |
|---|---|
| WASD / 矢印キー | 移動 |
| マウス | 照準 / 左クリックで射撃 |
| Space | ダッシュ（短時間無敵・逮捕ゲージも解除） |
| 1 / 2 / 3 またはクリック | 強化の選択 |
| Enter / クリック | 開始・リトライ |

## スマホ操作（横向き推奨）
| 操作 | 動作 |
|---|---|
| 画面左をドラッグ | 移動（仮想スティック） |
| 画面右をドラッグ | 照準＋自動連射（倒した方向に撃つ） |
| DASHボタン | ダッシュ（短時間無敵） |
| 強化カードをタップ | 強化を選択 |
| 画面タップ | 開始・リトライ |

## カスタマイズ
`index.html` 冒頭の `GOAL`、`STAR_AT`、`TYPES`、`SPAWN`、`ALLY`、`UPG`、`allyHp/allyDmg/allyRate` を編集すると、
クリア時間・手配度の上昇タイミング・敵や味方の性能・出現比率を変更できます。

## 公開（GitHub Pages）
リポジトリの Settings → Pages で `main` ブランチのルートを指定すると、そのままブラウザで遊べます。
